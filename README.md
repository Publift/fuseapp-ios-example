# Fuse App SDK iOS Example

Fuse is the [Publift](https://www.publift.com/) advertising solution for publishers of all sizes across web sites and apps.

This repository contains example code for the Fuse App SDK on iOS.

## Getting started

Choose an install method. Both apps build the same sample code from `Shared/`.

### Swift Package Manager (recommended)

1. Clone this repo
2. Open `SPM/FuseAppExample.xcodeproj` in Xcode
3. Build and run

### CocoaPods

1. Clone this repo
2. Run `cd CocoaPods && pod install`
3. Open `CocoaPods/FuseAppExample.xcworkspace` in Xcode
4. Build and run
